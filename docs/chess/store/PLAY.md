# Публикация «Шахмат царств» в Google Play

Готовый подписанный файл приложения: **kingdoms-chess-1.0.0.aab** (выдан отдельно вместе с ключом загрузки
`kingdomschess-upload.jks` и паролем). Пакет: `uz.kingdomschess.game`, версия 1.0.0 (код 1), Android 7.0+.
Приложение — Trusted Web Activity: открывает сайт игры `https://richerdsuper-pixel.github.io/kingdoms-chess/`
на весь экран, с оплатой через Google Play.

> ⚠️ Ключ загрузки и пароль храните в надёжном месте (облако + флешка). Без них нельзя выпускать обновления
> (Google может сбросить ключ загрузки по запросу, но это занимает дни). В репозиторий их не кладите.

## 1. Сайт игры (GitHub Pages)
1. Создайте на GitHub **публичный** репозиторий `kingdoms-chess` (пустой).
2. Скопируйте в его корень содержимое папки `docs/chess/` (кроме `store/`): `index.html`, `manifest.webmanifest`,
   `sw.js`, `icon-*.png`, `privacy.html`, папки `engine/` и `units/`.
3. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
   Через пару минут игра откроется по адресу `https://richerdsuper-pixel.github.io/kingdoms-chess/`.

## 2. Файл подтверждения домена (чтобы не было адресной строки)
Android проверяет файл `https://richerdsuper-pixel.github.io/.well-known/assetlinks.json` — он должен лежать
в корне домена, то есть в репозитории **`richerdsuper-pixel.github.io`**:
1. Создайте публичный репозиторий `richerdsuper-pixel.github.io`, включите Pages (ветка `main`, `/ (root)`).
2. Положите туда `.well-known/assetlinks.json` (образец — `docs/.well-known/assetlinks.json`) и пустой файл `.nojekyll`
   (иначе GitHub не отдаёт папки с точкой).
3. После первой загрузки AAB в Play Console откройте «Тестирование и выпуск → Настройки → Подпись приложений»,
   скопируйте **SHA-256 ключа подписи приложения** и вставьте его в `assetlinks.json` вместо заглушки.
   Отпечаток ключа загрузки (`1C:0E:8F:…:58:B6`) уже вписан.
Пока файла нет, игра всё равно работает — просто сверху будет видна адресная строка.

## 3. Play Console: создать приложение
1. «Создать приложение» → название «Шахматы царств», язык по умолчанию — русский, тип — **Игра**, **Бесплатное**.
2. Тестирование → **Внутреннее тестирование** → создать выпуск → загрузить `kingdoms-chess-1.0.0.aab`
   (подпись приложений Google Play — оставить включённой). Добавьте себя в тестировщики и установите по ссылке.
3. Новые личные аккаунты (после ноября 2023 г.) обязаны пройти **закрытое тестирование: минимум 12 тестировщиков
   14 дней подряд**, прежде чем откроется публикация для всех. Создайте закрытый трек и пригласите друзей/коллег.

## 4. Карточка в магазине
Тексты — `LISTING.md` (ru/uz/en), значок — `../icon-512.png`, баннер — `feature-graphic.png`,
скриншоты — `screenshots/01…06` (1080×1920). Политика конфиденциальности:
`https://richerdsuper-pixel.github.io/kingdoms-chess/privacy.html`.

## 5. Анкеты в Play Console
- **Возрастной рейтинг (IARC):** игра-шахматы; насилие мультяшное (фигуры «съедают» друг друга); кровь — только
  в необязательном взрослом режиме (по умолчанию выключен); покупки в приложении — да; реклама — нет.
- **Целевая аудитория:** рекомендуем **13+** (с детской аудиторией действуют правила программы Families).
- **Безопасность данных:** данные не собираются и не передаются; платежи обрабатывает Google Play.
- **Реклама:** нет. **Доступ к приложению:** без входа, все функции доступны.

## 6. Обновления
1. Обновили игру → залили файлы в репозиторий `kingdoms-chess` — игроки получат новое сразу, без обновления в Play.
2. Новый AAB нужен только при смене значка, названия, пакета или настроек Android: увеличьте `appVersionCode`
   в `twa-manifest.json`, пересоберите (`bubblewrap build` или Gradle `bundleRelease`) и подпишите тем же ключом.

## 7. Товары за деньги (Google Play Billing)

В `twa-manifest.json` уже включено `"playBilling": { "enabled": true }` (minSdk 24). После `bubblewrap build`
в Play Console → «Монетизация → Товары → Встроенные товары» создайте **одноразовые (non-consumable)** товары
с такими идентификаторами — игра сама подтянет из Google Play их цены и восстановит покупки на новом телефоне.
Покупка подтверждается библиотекой TWA после `complete('success')`.
