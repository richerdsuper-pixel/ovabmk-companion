# OvaBMҚ Companion

Электронные папки-дела по охране материнства и детства (Шурчинское районное медицинское объединение).

* **Сайт:** `docs/` — статичные файлы для GitHub Pages (без сборки).
* **База и вход:** `supabase/` — миграции Postgres (Supabase) и функция `tg-login`.
* **Показатели:** раздел «Показатели» на сайте — только числа за период по должностям; список показателей `docs/indicators.js` собирается скриптом `tools/gen_indicators.py` из файлов Baza_NN.
* **Офлайн-программа:** `offline/` — один HTML-файл без интернета (импорт Excel от специалистов, напоминания, поиск по данным пациентов, шифрование; вкладка «Визиты» — пациенты по № карты, беременные по стандарту приказа №180 (ДПМ → срок, окна визитов, анализы, пропущенные визиты; всё на устройстве), махалля/улица/диагноз, фото осмотра с камеры телефона, напоминания, отправка для будущего сервера; всё только на устройстве). Сборка: `python3 offline/build.py`, проверка: `python3 offline/tests/test_offline.py` и `python3 offline/tests/test_cases.py`.
  Для телефонов — устанавливаемое приложение: https://richerdsuper-pixel.github.io/ovabmk-companion/app/ (Chrome → «Установить приложение»; работает без интернета). Администратор отправляет доя ссылку-приглашение со своим открытым ключом: файлы доя шифруются этим ключом (ECDH P-256 + AES-GCM) и открываются только в программе администратора — без паролей.
  При первом запуске выбирается должность: **доя кабинета** (беременные по приказу №180 — ДПМ, срок, анализы, группа риска, возрастная группа; списки скрининга по приказам №210 и 47-Т: осмотр 15–49 лет раз в год, шейка матки 35–55 раз в 3 года, молочная железа 45–65 раз в 2 года), **патронажная доя** (патронаж по приказу №210, приложение 2: беременная 12 и 32 нед., родильница и новорождённый — 3 раза) или **администратор**. Вкладка «Сегодня» — обход по махаллям и улицам; «Отчёт» — числа за месяц и файл с числами для сайта (без людей), кнопка «Отправить администратору» (зашифрованный файл, только изменения; Ф.И.О./телефон/адрес — только если изменились; код отправки задаётся один раз и больше не спрашивается, на телефоне сразу открывается «Поделиться»), календарь на все будущие визиты. Языки: русский, узбекский (кириллица и латиница); тексты приказа №180 по-узбекски — `offline/anc.json`.
* **Проверки:** `tests/` — тесты прав доступа (локальный Postgres), подписи Telegram и интерфейса.

## Как устроен доступ

| Роль | Что может |
|---|---|
| Администратор | всё, кроме папки №15; сотрудники, роли, приглашения, журнал, удаление документов |
| Заместитель, Главный врач | читать и добавлять документы во всех папках, кроме №15 |
| Сотрудник | читать и добавлять документы только в назначенных папках; вносить и править свои показатели |

* Вход — только через Telegram: по одноразовому приглашению или по заявке. Общая ссылка на сайт: человек входит через Telegram, пишет ФИО и выбирает должность; администратор в разделе «Заявки» видит папки, отмеченные по должности автоматически (`docs/positions.js`), при необходимости меняет их и одобряет или отклоняет. До одобрения учётная запись не создаётся и доступа к данным нет.
* Роли меняются только функциями базы, которые сами проверяют роль администратора; из браузера записать роль нельзя.
* Папка №15 «Материнская смертность» закрыта для всех, включая администратора (проверка в базе и в хранилище файлов).
* Документы с данными пациентов (ФИО, ПИНФЛ, диагнозы) загружать нельзя: при загрузке это нужно подтвердить, а база не примет документ без подтверждения.
* Показатели: сотрудник видит и правит только свои отчёты, руководители видят все. В таблице только числа (база отклоняет текст, чужие ключи и огромные значения), поэтому внести туда данные пациентов нельзя.
* Все действия пишутся в журнал (виден администратору).

## Настройка (один раз)

1. **Бот:** @BotFather → `/newbot`; затем `/setdomain` → `richerdsuper-pixel.github.io`.
2. **Токен бота:** Supabase → проект → Edge Functions → Secrets → `TELEGRAM_BOT_TOKEN`. Токен никому не пересылайте.
3. **Регистрация:** Supabase → Authentication → Sign In / Providers → выключить «Allow new users to sign up» (вход по приглашениям работает и без неё).
4. **GitHub Pages:** Settings → Pages → Deploy from a branch → `main` / `docs`.
5. **Первый администратор:** Supabase → SQL Editor:
   ```sql
   select private.make_invite(null, 'admin', 'ФИО', 'Должность', '{}', 24);
   ```
   Запрос вернёт код. Откройте `https://richerdsuper-pixel.github.io/ovabmk-companion/?invite=КОД` и войдите через Telegram. Ссылка одноразовая и действует 24 часа. Дальше сотрудников приглашаете из раздела «Приглашения».

## Данные пациенток и сайт

На сервере не хранятся записи о беременных и вообще данные пациентов: страница «Беременные (стандарт)» — помощник, срок считается в браузере по введённой дате и нигде не сохраняется
(миграция 0013 удалила таблицы и ночные задания; остался только справочник окон визитов `anc_schedule`, который правит администратор).
Отслеживание конкретных пациенток — только на устройстве, в офлайн-программе (модуль «Визиты»). Edge Function `anc-digest` отключена (отвечает 410) — её можно удалить в панели Supabase.
Сайт на трёх языках: Рус, Ўзб (кириллица) и Oʻzb (латиница; получается автоматической транслитерацией узбекских текстов).
